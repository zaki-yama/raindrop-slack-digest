## 1. [Announcing TypeScript 7.1 Beta - TypeScript](<https://devblogs.microsoft.com/typescript/announcing-typescript-7-1-beta/>)

devblogs.microsoft.com

TypeScript 7.1 Beta の紹介記事。ambient module での import attributes、source phase imports、es2026 ターゲットといった言語・ライブラリ面の更新に加え、新しいプログラマティック API と content mappers を導入する。多数の最適化で速度とメモリも改善し、分配的条件型のチェックは厳格化された。

- `declare module "*" with { type: "css" }` の形で import attributes を ambient module 宣言に書け、属性の付け忘れをエラーにできる。
- `import source` と `import.source()` に対応し、WebAssembly のソースを `WebAssembly.instantiate` に渡せる。型は `AbstractModuleSource`。
- `--target`/`--lib` に es2026 が加わり、`Math.sumPrecise()` や `Array.fromAsync()` などが安定版の lib に入った。
- 新 API は `typescript/sync`、`typescript/async`、`typescript/fs` などに分割され、Snapshot による差分更新と仮想ファイルシステムを扱える。
- content mappers を tsconfig に登録すると .vue などの埋め込みコードを検査できる。実行には `--runExternalCode` が必要。
- 5つのコードベースで 7.0 比 1.2〜1.9 倍に高速化し、メモリ使用量は 15.8〜49.6% 減った。
- 分配的な型パラメータの制約チェックが厳格になり、既存の型定義で新たにエラーが出る場合がある。

## 3. [Fundamental Resources](<https://basecamp.com/managers/fundamental-resources>)

basecamp.com

37signalsでマネージャーとして成果を出すために必要な社内資料を紹介するページ。プレイブックの後続章から参照される基本資料として、ハンドブック、職種別のキャリア進行フレームワーク、評価フォーム、組織図、過去の求人例が挙げられている。

- 37signals Employee Handbookは、全社員向けの会社ポリシーをまとめた一般的なハンドブックである。
- キャリア進行フレームワークはDesigners、Ops、Programmers、QA、Customer Supportの職種ごとにあり、シニアリティ別に整理されている。
- 各フレームワークは、各レベルで期待されるSkills、Engagement、Coachabilityを示す。
- 年次の業績評価はフレームワークに対応しており、マネージャーは年間を通じた簡易的な評価の確認にも使う。
- 評価フォームと自己省察フォームは参考用の写しで、実際の評価時にはJotformのアンケートが割り当てられる。
- 組織図は全社のチーム構造と階層を示す。過去の求人は参考用で、そのまま再利用はしない。

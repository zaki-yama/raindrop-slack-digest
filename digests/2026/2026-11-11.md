## 1. [Modern Web Guidance 1.0: The web platform expertise your coding agent is missing | Blog | Chrome for Developers](<https://developer.chrome.com/blog/modern-web-guidance-v1>)

developer.chrome.com

Chromeは、Webプラットフォームの知見やブラウザ互換性データをコーディングエージェントに組み込む「Modern Web Guidance」の1.0安定版を公開した。モダナイズ workflow の追加、ガイドの拡充と専門家レビュー、公開 eval dashboard が主な内容である。Firefox と Edge も加わるクロスブラウザの取り組みになり、Chrome DevTools for agents との併用や導入事例も紹介されている。

- 1.0では既存の HTML・CSS・JavaScript・package.json を静的解析し、安全にモダナイズできる箇所を探す workflow が加わった。
- 現状の解析は限られたパターンのみが対象で、今後はエージェント自身がコードを読んで監査する方式まで広げる予定である。
- ガイドは Baseline と互換性データを埋め込み、ブラウザ対応要件に合わせて機能を推奨する。ユーザー向けガイドは支援技術を使う専門家がアクセシビリティを検証した。
- Chrome DevTools for agents と併用すると、性能トレース、アニメーション確認、メモリリーク検証など実行時の検証もエージェントに任せられる。
- note inc. は180回の評価で合格率が61%から94%に上がり、MetaMask は PR レビュー bot として約480件中64件にコメントし、43件が修正された。

## 2. [Modern Web Guidance がコードベースをモダナイズする仕組みと、それを行うべき理由 | Chrome for Developers](<https://developer.chrome.com/docs/modern-web-guidance/modernization-workflow?hl=ja>)

developer.chrome.com

Chrome for Developersの記事で、Modern Web Guidance 1.0 の新機能であるモダナイゼーション ワークフローを紹介している。既存コードのレガシーなパターンをlegacy-scanで検出し、コーディング エージェントが最新のBaseline機能へリファクタリングする仕組みと、その手順や変換例を説明している。

- レガシーコードは動作し続けるため放置されがちだが、バンドルサイズ、応答性、ユーザー補助に静かに影響し、エージェントも古いパターンを複製してしまう。
- legacy-scanはAST、DOM、CSSパーサーでHTML/CSS/JS/TS/package.jsonをローカルでスキャンし、LLM呼び出しやトークン費用がかからない。
- ルールは約45,000のOSSリポジトリを半分ずつに分けて作成と評価を行い、静的マッチャー精度80%以上、検証後精度90%以上を満たしたものだけを出荷する。
- 検出対象は約200ガイド（約20%）に限られ、各一致にkeepWhen/dropWhenのルーブリックが付き、エージェントが文脈から誤検出を除外する。
- --fixフラグはなく、スキャン、文脈検証、報告、ガイド取得とリファクタリングおよびテスト検証の4ステップで進める。CI/CD統合は開発中。
- 変換例として、scrollHeightによるtextarea自動拡張をfield-sizing: contentに、click listenerをpopovertargetに置き換え、IME対応のEnter送信ガードを追加する例が挙がる。
